# Express workshop runtime archive

The original Express and SQLite demo was used during the AI development workshop as a learning baseline. Its runnable source and setup scripts have been retired after the Nx Angular and NestJS product implementation replaced them.

This note preserves the history only. The application is not supported or runnable from this repository. Use the Nx workspace documented in the root README for development and testing. The original workshop brief and generated workshop artifacts remain available in their respective directories.
